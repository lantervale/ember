# li

![A pack's contents, each item a line with its marker before it](ul.png "ember · ul")

```go
ui.Ul(
	ui.Li(ui.Text("Iron sword")),
	ui.Li(ui.Text("A map of the crypt")),
)
```

| Attribute | |
|---|---|
| `ui.Text(s)` | its text; children may be any elements, a list among them |
| `value` | the item's number, the items after it counting on from it |

A list's item: a block with a marker outside it, to its left. The marker is its `list-style-type`, inherited from its list: `disc`, `circle`, `square`, its number (`decimal`, `decimal-leading-zero`, `lower-alpha`, `upper-alpha`, `lower-roman`, `upper-roman`) or `none`. The number is the `list-item` counter: one more than the item before, one less in a `reversed` list, or the item's `value`; `counter(list-item)` reads it in a `content`. `li::marker` styles the marker (colour, font, `content`), and `li::before` or `li::after` add a box inside the item ([pseudo-elements](../03-css.md#pseudo-elements)). By default a `ul` or `menu` gives discs, circles inside another list and squares two lists deep; an `ol` gives numbers at any depth.

| Default CSS | |
|---|---|
| `li` | `display: list-item` |

Automation: recorded, as a label, only when it has an `id`.
