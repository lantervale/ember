# i

![The Heron sails at dawn, Heron in italics](i.png "ember · i")

```go
ui.P(ui.Text("The "), ui.I(ui.Text("Heron")), ui.Text(" sails at dawn."))
```

| Attribute | |
|---|---|
| `ui.Text(s)` | its text; children may be any inline elements |

Text in another voice, a name or a foreign word; it looks as [`em`](16-em.md) does.

| Default CSS | |
|---|---|
| `i` | `font-style: italic` |

Automation: recorded, as a label, only when it has an `id`.

```
go run ./examples/93-html-elements -element i
```
