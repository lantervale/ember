# br

![A sign's two lines in one paragraph: North: the mill over South: the old bridge](br.png "ember · br")

```go
ui.P(
	ui.Text("North: the mill"),
	ui.Br(),
	ui.Text("South: the old bridge"),
)
```

Ends the line it is in: what follows starts the next one. It has no children and no box of its own to style.

| Default CSS | |
|---|---|
| `br` | none |

```
go run ./examples/93-html-elements -element br
```
