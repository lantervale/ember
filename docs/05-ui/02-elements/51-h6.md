# h6

![Deadzone in bold, much smaller than the line of body text under it](h6.png "ember · h6")

```go
ui.H6(ui.Text("Deadzone"))
ui.P(ui.Text("A tenth of the stick's travel."))
```

| Attribute | |
|---|---|
| `ui.Text(s)` | its text; children may be any inline elements |

| Default CSS | |
|---|---|
| `h6` | `display: block; margin: 2.33em 0; font-size: 0.67em; font-weight: bold` |
