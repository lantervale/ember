# s

![Lantern: 25 gold, then 18 gold, the first price struck through](s.png "ember · s")

```go
ui.P(ui.Text("Lantern: "), ui.S(ui.Text("25 gold")), ui.Text(" 18 gold"))
```

| Attribute | |
|---|---|
| `ui.Text(s)` | its text; children may be any inline elements |

Text that no longer holds, an old price for one: struck through.

| Default CSS | |
|---|---|
| `s` | `text-decoration: line-through` |

Automation: recorded, as a label, only when it has an `id`.

```
go run ./examples/93-html-elements -element s
```
