# q

![The smith said “bring me the key” and turned away, the quotation between curly marks](q.png "ember · q")

```go
ui.P(ui.Text("The smith said "), ui.Q(ui.Text("bring me the key")), ui.Text(" and turned away."))
```

| Attribute | |
|---|---|
| `ui.Text(s)` | its text; children may be any inline elements |

A short quotation inside a line: its text stands between “ and ”, a `q` inside another between ‘ and ’, and so do those deeper. The marks are generated boxes: `quotes` chooses them (`quotes: "«" "»" "‹" "›"`, or `none`), the last pair serving any deeper `q`, and `q::before` and `q::after` restyle or replace them ([quotes](../03-css.md#quotes)). Its `cite` attribute shows nothing.

| Default CSS | |
|---|---|
| `q` | inline, as [`span`](14-span.md) |
| `q::before`, `q::after` | `content: open-quote`, `content: close-quote` |

Automation: recorded, as a label, only when it has an `id`.

```
go run ./examples/93-html-elements -element q
```
