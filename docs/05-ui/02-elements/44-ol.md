# ol

![A quest's three steps numbered 1 to 3, then two more numbered 4 and 5](ol.png "ember · ol")

```go
ui.Ol(
	ui.Li(ui.Text("Find the lost key")),
	ui.Li(ui.Text("Open the cellar door")),
	ui.Li(ui.Text("Light the beacon")),
)
ui.Ol(ui.Attr("start", "4"),
	ui.Li(ui.Text("Return to the smith")),
	ui.Li(ui.Text("Claim the reward")),
)
```

| Attribute | |
|---|---|
| `start` | the first item's number, 1 unless set, the number of items in a `reversed` list |
| `reversed` | the items count down |

A list whose items are in order: each [`li`](45-li.md) has its number and a dot outside it, in the list's left padding. An item with `display: none` takes no number. The numbers are the `list-item` counter, which the list resets and each item moves by one ([counters](../03-css.md#counters)): a sheet numbers a list its own way with `counter-reset`, `counter-increment` and `li::before { content: counters(item, ".") }`, and styles the numbers with `li::marker`. The list's `type` attribute is not read: use `list-style-type`.

| Default CSS | |
|---|---|
| `ol` | `display: block; margin: 1em 0; padding-left: 40px; list-style-type: decimal` |
| any list in a list | `margin-top: 0; margin-bottom: 0` |

Automation: recorded, as a label, only when it has an `id`.

```
go run ./examples/93-html-elements -element ol
```
