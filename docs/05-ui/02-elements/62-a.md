# a

![Read the patch notes or the old ones, patch notes in blue and underlined](a.png "ember · a")

```go
ui.A(ui.Attr("href", "notes"), ui.Text("patch notes"), ui.OnClick(func() { showNotes() }))
ui.A(ui.Text("the old ones"))
```

| Attribute | |
|---|---|
| `ui.Text(s)` | its text; children may be any inline elements |
| `href` | makes it a link: it matches `:link`, takes the focus and clicks |
| `ui.TabIndex(i)` | its place in the Tab order; -1 leaves it out |

ui opens nothing itself: the `href` is not followed, and what a click does is the link's `ui.OnClick`. No link is ever `:visited`. An `a` without an `href` is plain text.

| Default CSS | |
|---|---|
| `a:link` | `color: #0000ee; cursor: pointer; text-decoration: underline` |
| `a:link:active` | `color: #ff0000` |

| Event | When |
|---|---|
| `ui.Clicked{Node}` | with an `href`: a click, Enter while focused, the pad's South, or automation's press |

Automation: with an `href`, its `id`, else `data-name`, `aria-label`, then the slug of its text (`patch-notes`); `press`. Without one, recorded, as a label, only when it has an `id`.
