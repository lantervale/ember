# h5

![Left stick in bold, smaller than the line of body text under it](h5.png "ember · h5")

```go
ui.H5(ui.Text("Left stick"))
ui.P(ui.Text("Moves the hero."))
```

| Attribute | |
|---|---|
| `ui.Text(s)` | its text; children may be any inline elements |

| Default CSS | |
|---|---|
| `h5` | `display: block; margin: 1.67em 0; font-size: 0.83em; font-weight: bold` |

Automation: recorded, as a label, only when it has an `id`.

```
go run ./examples/93-html-elements -element h5
```
