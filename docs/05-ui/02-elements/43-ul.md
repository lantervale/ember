# ul

![A pack's contents as a list with discs, Potions holding a list with circles, Healing one with a square](ul.png "ember · ul")

```go
ui.Ul(
	ui.Li(ui.Text("Iron sword")),
	ui.Li(ui.Text("Potions"),
		ui.Ul(
			ui.Li(ui.Text("Healing"), ui.Ul(ui.Li(ui.Text("Two flasks")))),
			ui.Li(ui.Text("Mana")),
		),
	),
	ui.Li(ui.Text("A map of the crypt")),
)
```

Its `type` attribute (`disc`, `circle`, `square`, `none`, in any case) picks the bullets as in Chrome, under every rule of the sheets.

A list whose items are in no order: each [`li`](45-li.md) has a disc outside it, in the list's left padding. A `ul` in another list (`ul`, `ol` or `menu`) has circles, one two lists deep squares, and a list in a list has no margin above or below. `li::marker` styles the bullets, and its `content` replaces them: `li::marker { content: "+ "; color: #b0493c }` ([pseudo-elements](../03-css.md#pseudo-elements)).

| Default CSS | |
|---|---|
| `ul` | `display: block; margin: 1em 0; padding-left: 40px; list-style-type: disc` |
| a `ul` in a `ul`, `ol` or `menu` | `list-style-type: circle` |
| a `ul` in two of them | `list-style-type: square` |
| any list in a list | `margin-top: 0; margin-bottom: 0` |

Automation: recorded, as a label, only when it has an `id`.
