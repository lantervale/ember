# b

![You picked up the Iron sword, Iron sword in bold](b.png "ember · b")

```go
ui.P(ui.Text("You picked up the "), ui.B(ui.Text("Iron sword")), ui.Text("."))
```

| Attribute | |
|---|---|
| `ui.Text(s)` | its text; children may be any inline elements |

Text that stands out without more weight in meaning; it looks as [`strong`](15-strong.md) does.

| Default CSS | |
|---|---|
| `b` | `font-weight: bold` |

Automation: recorded, as a label, only when it has an `id`.

```
go run ./examples/93-html-elements -element b
```
