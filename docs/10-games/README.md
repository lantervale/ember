# Games

Small, whole games made with ember, each a few files you can read in one sitting. They show how the sections fit together:

- the rules in plain Go;
- the board a 2D entity, with particles and tweens;
- the HUD and menus in ui, beside the board;
- the music and sounds made in code;
- the keyboard or a gamepad through an action map, the prompts switching to the device last used.

They share one look, Kenney's pixel UI and input prompts (CC0), and one menu: new game, leaderboard, music and sound.
